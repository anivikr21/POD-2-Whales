# POD 2 : Whales — LipidLens

A lightweight UI for uploading structured clinical data to screen for familial hypercholesterolemia (FH).

Open `index.html` in a browser to use the prototype. The interface validates CSV file type and a 10 MB size limit, then presents a ready-for-inference state. Connect the Analyze action to the team's model API to return the final positive/negative classification.
