Result interpretation

What each class means

These are machine-learning classifications of genetic variants. They are not patient diagnoses and require expert review.

Class 01Benign

The model found features associated with variants classified as benign.

Review guidance

  • Confirm the source data and genomic build.
  • Review current ClinVar evidence.
  • Do not use this output alone for care decisions.
Class 02Uncertain / conflicting

Available model features do not support a clear benign or pathogenic classification.

Review guidance

  • Inspect conflicting submissions.
  • Check functional and segregation evidence.
  • Escalate for specialist interpretation.
Class 03Pathogenic

The model found features associated with variants classified as pathogenic.

Review guidance

  • Confirm the variant and transcript.
  • Review expert-panel assertions.
  • Seek qualified clinical interpretation.
